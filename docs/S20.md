# Galaxy S20+ (y2s, SM-G986B, Exynos 990)

Boot chain: stock S-Boot (unchanged) loads `boot.img` like an Android kernel.
The "kernel" is the y2s shim (`shim/`) with the xnu payload appended to it
(`tools/mkpayload.py`: kernel + ADT + boot-args); the ramdisk and dtb are the
stock ones. S-Boot did not start an image whose ramdisk was the 16 MB payload. The shim copies xnu to
RAM, builds `boot_args` and jumps to it, like iBoot.

Hardware facts used (from `~/ios-s20/live.dts`, the stock kernel's live DT):

| What | Value |
|---|---|
| Entry | EL1 (Samsung hypervisor at EL2), MMU off, x0 = DTB |
| Payload | appended to the shim image, found at the linker symbol `_end` |
| Framebuffer | 0xF1000000, 1440x3200 a8r8g8b8 (`s3cfb.bootloaderfb`) |
| GIC | `arm,cortex-a15-gic` (GIC-400): GICD 0x10101000, GICC 0x10102000 |
| Timer | 26 MHz, virtual timer PPI 11 = INTID 27 |
| xnu RAM | 0x9A000000 + 512 MiB (low bank, clear of every static carve-out) |
| CPUs | MPIDR 0x000-0x005, 0x100, 0x101; only the boot CPU is used (`cpus=1`) |

Not ported yet: SMP, Exynos UFS (so no iOS root on storage), touch, buttons,
USB, battery. The Qualcomm drivers only start with a `/y2s-ufs` ADT node,
which the S20 ADT does not have.

## Build and test (Linux laptop)

Paths assume the clone at `~/ios-s20/ios-sweet` and the stock boot.img
unpacked to `~/ios-s20/unpack/` (`dtb` and `ramdisk` are taken from there).

1. Kernel: download the `xnu-kernel` artifact of the latest green "xnu" run
   of the fork and unzip it into `xnu/out/` (gives `kernel.development.y2s`).
2. QEMU, kernel only:

   ```
   python3 tools/mkadt.py /tmp/q.adt --qemu
   python3 tools/mkpayload.py xnu/out/kernel.development.y2s /tmp/q.adt /tmp/q.bin --cmdline 'debug=0xc serial=3 cpus=1 keepsyms=1 -enable_kprintf_spam rd=md0'
   python3 tools/qemu-y2s.py /tmp/q.bin /tmp/q-run --secs 30
   ```

3. QEMU through the real shim (needs `aarch64-linux-gnu-gcc` and `mkbootimg`):

   ```
   shim/build.sh /tmp/q.bin
   python3 tools/qemu-y2s.py /tmp/q.bin /tmp/q-shim --shim shim/out/Image --secs 30
   ```

4. Phone boot.img:

   ```
   python3 tools/mkadt.py /tmp/s20.adt
   python3 tools/mkpayload.py xnu/out/kernel.development.y2s /tmp/s20.adt /tmp/s20.bin --cmdline 'debug=0xc serial=3 cpus=1 keepsyms=1 -enable_kprintf_spam'
   shim/build.sh /tmp/s20.bin
   ```

   Flash from TWRP (adb push to /sdcard fails there; /tmp works):

   ```
   adb push shim/out/y2s-boot.img /tmp/ && adb shell "dd if=/tmp/y2s-boot.img of=/dev/block/by-name/boot" && adb reboot
   ```

   Restore the stock `boot.img` from `~/ios-s20/backup/` the same way.

Expected first result: a green band at the top (first instruction of the
shim), then the red shim screen with EL/DTB/INITRD lines, then xnu's
console, ending at `Waiting on <dict>...IOMedia...` (no root device yet),
as the Redmi did at the same milestone.

## Status (2026-10-20, handoff)

Working on the phone: S-Boot -> shim (green band, DECON trigger unmask) ->
xnu; GICv2, timer, SGI; framebuffer console; 4 GiB RAM at 0x8_8c00_0000
(mkadt default; `--lowmem` = old 512 MiB); Exynos UFS (xnu 0084): device
woken with START STOP UNIT to W-LUN 0xD0 (sense 2/04/02 after S-Boot), GPT
read, `userdata` found (first block 0x2b7e00, 110868 MiB), HFS+ volume
header of the iOS root read.

Known UFS quirk: the request list stops (UTRLRSR reads 0, HCS 0x10f) between
commands after idle; the driver restarts it once and the retry succeeds
("request list restarted, retry: 0"). Cause unknown.

Last change (run 39476206681, untested): Exynos PRDT entries of max 4 KiB
(the 8 KiB catalog node read back as zeros with one 256 KiB entry). The
root on userdata was written to before this fix: rewrite ios16-root.img
before testing.

iOS root: ~/ios-s20/ios16-root.img (iPhone10,3 16.7.16 20H392, mkiosroot.sh
16G + y2s-root-tweaks.py), D22AP /product from research/ipsw-x/d22ap.adt.
Write from TWRP: `adb exec-in "dd of=/dev/block/by-name/userdata bs=4194304" < ios16-root.img`.

Boot-args used:
`debug=0xc serial=3 cpus=1 keepsyms=1 -enable_kprintf_spam -noprogress rd=ufsroot0 ufsrw=1 rootrw=1 unentitled_ios_sim_launch=1 ignition_level=1 wdt_test=no_user_checkin launchd_unsecure_cache=1 wdt=-1 y2sfb_hz=30`

Next: root mount -> launchd; present the 1440x3200 panel as iPhone X
1125x2436 (Y2SFramebuffer only does that for panels <= 1125x2436); SMP
(Y2SCPU expects Aff0 == 0, S20 MPIDRs are 0x000-0x005/0x100/0x101);
touch, buttons, USB.
